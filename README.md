# EasyCare

Aplicação desenvolvida para facilitar o **gerenciamento de informações médicas**, reunindo exames, prontuários, consultas, dados pessoais de saúde e outras informações importantes em um único lugar.

O projeto também prevê recursos de **compartilhamento familiar**, calendário de consultas e exames, localização de unidades de saúde próximas e ferramentas de acessibilidade.

**Site:** https://vinibrtl.github.io/EasyCare/

## Principais funcionalidades

| **Funcionalidade** | **Como funcionará** |
| --- | --- |
| **Gerenciamento de prontuários** | O usuário poderá armazenar e acessar exames, receitas e outros documentos médicos |

| **Localização de atendimentos** | O sistema ajudará a encontrar unidades de saúde próximas |

## Funcionamento

O usuário poderá criar uma conta ou realizar login no EasyCare.

Após entrar no sistema, será direcionado para a **página principal**, onde poderá visualizar informações importantes relacionadas à sua saúde.

Pelo menu de navegação, será possível acessar os principais recursos da aplicação, como:

- exames e prontuários;
- compartilhamento familiar;
- calendário;
- vínculo com sistemas;
- unidades de atendimento próximas;
- informações da conta.

A proposta é concentrar essas informações em um único ambiente, facilitando o acompanhamento e a organização da saúde do usuário.
